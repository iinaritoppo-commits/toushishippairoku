## 戒名生成ロジック（v1）

階位は損失額で決定：
- 100-300万: `信士／信女`（最低位）
- 300-500万: `居士／大姉`
- 500-1000万: `院信士／院信女`
- 1000-3000万: `院居士／院大姉`
- 3000万-1億: `大居士／清大姉`
- 1億超え: `院殿大居士／院殿清大姉`

中央2文字はカテゴリ＋ペルソナの特徴：
- FX破産: `為替惨敗／円損／逆指失敗／全損為替`
- 仮想通貨: `仮想塵／草損／暗号塵／NFT砕`
- 投資詐欺: `欺被害／詐欺塵／騙被害／信用断`
- 信用取引: `追証塵／信用断／レバ砕／全損信用`
- 不動産: `不動破／空室塵／家賃断／土地砕`
- 副業: `副業塵／高額塵／MLM塵／情報塵`

頭は投稿者のイニシャル（例: Tさん → 「T院為替惨敗大居士」）

## SEO戦略まとめ

- **タイトル**：`{損失額} {カテゴリ} {年代}{職業} {きっかけ}` を含む
  - 例：「FXで全財産320万円を溶かした30代会社員、トルコリラショック当日の話」
- **description**：年代・職業・損失額・きっかけ・教訓 を120字
- **本文構造**：
  - 冒頭：投稿者プロフィール＋金融イベント説明（リサーチ感）
  - 経緯：時系列・具体額・取引画面の描写
  - クライマックス：ロスカット/破産発覚の瞬間
  - 現在：返済中/復活/破産手続き等
  - 教訓：「同じ失敗をしないために」3項目
  - 戒名（強調なし、最後にひっそり）
- **内部リンク**：同カテゴリ3本＋金融イベント関連3本＋同県別1本
- **構造化データ**：Article / BreadcrumbList / Person（投稿者）
