## 記事の型（jirei既存6本と統一）
1. タイトル: 「{事件名}とは何だったか ─ {一言の構造}（{被害規模}）」
2. 体験者プロフィール枠 → 「事件概要」枠に置換（発生年・主体・被害総額・結末/判決）
3. 本文: 勧誘の入口 → スキームの構造 → 崩壊の経緯 → 司法の結末 → 現代への教訓（同型の現行手口に接続）
4. fact-table: 被害総額・被害者数・判決・返金率
5. 管理人の感想: しら視点で「現代の何に似ているか」を必ず1本接続（既存記事への内部リンク）
6. ソース: 消費者庁公表資料・判決報道に基づく旨を明記（「※公開情報に基づく事件記録です」）
